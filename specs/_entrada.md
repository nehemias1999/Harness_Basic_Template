# Entrada de requisitos en crudo

> Captura **append-only** de lo que pide el humano, **con sus palabras**. La
> escribe el agente `analyst` antes de interpretar nada, y cada requisito de
> `specs/REQ-*.md` cita de qué entrada salió.
>
> Existe por una razón concreta: dentro de dos meses, cuando un spec diga algo
> raro, esto es lo único que permite distinguir "lo pidió así" de "el agente lo
> inventó". Nunca se edita ni se borra una entrada anterior.

Formato de cada entrada:

```markdown
## <YYYY-MM-DD> — ronda <N>

> <lo que dijo el humano, textual>

-> REQ-001, REQ-002
```
